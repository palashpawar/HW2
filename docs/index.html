Every image on this site is a numeric matrix X that has been rebuilt from just its first few principal components. The four images come from the course Canvas page as CSV matrices; each page below works through one of them.

The idea

Let V = X'X and take its eigendecomposition V = UΛU'. Because U is orthonormal, X = XUU', so with the principal component scores Z = XU we get the exact identity X = ZU'. Truncating that sum after k terms gives the rank-k approximation

X(k) = z1u1' + z2u2' + … + zkuk'

and the quality of that approximation is measured by the Frobenius norm of what is left over, Error(k) = ‖X − X(k)‖F. Storing X(k) only requires the k score columns and k eigenvectors, i.e. k(n + p) numbers instead of n × p — that is where the compression comes from.

Two facts worth keeping in mind while reading the pages:

  • No centering. The identity X = ZU' only holds if the columns are not centered, so the eigendecomposition is taken of X'X directly (in R this is prcomp(X, center = FALSE), not the default).
  • The error is set by the discarded eigenvalues. Because the rank-1 pieces are mutually orthogonal, ‖X − X(k)‖F2 = λk+1 + … + λp. The script checks this identity against the norms it computes directly; they agree to ~1e−11.

The compression function

This is the function the assignment asks for: it takes an image matrix and a rank k, and returns the rank-k approximation together with its Frobenius error.

## SDS 365 - Homework 2
## PCA-based image compression

## Rank-k PCA approximation of an image matrix.
##
## X: an n x p numeric matrix (the image)
## k: rank of the approximation (1 <= k <= p)
##
## Returns a list with
##   approx: the rank-k approximation X^(k) = z_1 u_1' + ... + z_k u_k'
##   error : ||X - X^(k)||_F, the Frobenius norm of the approximation error
pca_compress <- function(X, k) {
  X <- as.matrix(X)
  p <- ncol(X)

  if (!is.numeric(k) || length(k) != 1 || k < 1 || k > p) {
    stop("k must be a single number between 1 and ncol(X) = ", p)
  }

  V <- crossprod(X)                  # V = X'X  (p x p)
  eig <- eigen(V, symmetric = TRUE)  # V = U Lambda U'
  U <- eig$vectors                   # p x p eigenvectors, decreasing eigenvalue
  Z <- X %*% U                       # n x p principal component scores

  idx <- seq_len(k)
  Xk <- Z[, idx, drop = FALSE] %*% t(U[, idx, drop = FALSE])

  list(approx = Xk, error = norm(X - Xk, type = "F"))
}

## Same decomposition, but computed once so that many values of k can be
## evaluated without repeating the eigendecomposition. Used by the analysis
## script and the Shiny app; pca_compress() above is the stand-alone answer.
pca_decompose <- function(X) {
  X <- as.matrix(X)
  eig <- eigen(crossprod(X), symmetric = TRUE)
  list(X = X, U = eig$vectors, Z = X %*% eig$vectors, values = eig$values)
}

pca_rank_k <- function(fit, k) {
  idx <- seq_len(k)
  Xk <- fit$Z[, idx, drop = FALSE] %*% t(fit$U[, idx, drop = FALSE])
  list(approx = Xk, error = norm(fit$X - Xk, type = "F"))
}

Usage:

X   <- as.matrix(read.csv("HW2imagefiles/image3.csv"))
out <- pca_compress(X, k = 30)

out$error          # 38.16  =  ||X - X^(30)||_F
dim(out$approx)    # 376 345, the compressed image

pca_decompose() / pca_rank_k() in the same file are a convenience: they do the eigendecomposition once so that hundreds of values of k can be evaluated without repeating it. They return exactly the same numbers as pca_compress(), which the analysis script verifies at several ranks.
